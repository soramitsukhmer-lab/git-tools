## About

[@soramitsukhmer](https://github.com/soramitsukhmer) git tools, see [soramitsukhmer/homebrew-tap](https://github.com/soramitsukhmer/homebrew-tap)

## Usage

```sh
brew tap soramitsukhmer/tap
brew search soramitsukhmer/tap | grep git-

# e.g: installing `soramitsukhmer/tap/soramitsukhmer-git-hooks-config`
brew install soramitsukhmer/tap/soramitsukhmer-git-hooks-config
```
